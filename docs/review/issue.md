# 現存する問題点
本ファイルはコードレビューによって見つかった問題点がまとめられているファイルです。<br>
問題点によって項目を分け、項目によっては危険度を基準に並び替えが行われています。<br>
各回のレビュー記録は [history/](history/) にあります。問題が解消したら、該当行をこのファイルから削除し、解消した変更をレビュー記録に書きます。<br>

## 設計の矛盾
エンジンやその部品の設計どうしで発生している矛盾を指摘する項目です。<br>
**内部設計や設計規則そのものの問題点**と言い換えることもできます。<br>
全ての問題が重大な問題であり危険度が付けられないため、危険度による並び替えは行いません<br>
|                概要                | 内容                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| :--------------------------------: | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
|   Render 層と Scene 層の相互参照   | [内部設計](../internal/InternalDesign.md) は「上の層から下の層へだけ依存する」と定めていますが、Render 層のパス（`OpaquePass`、`LightSetupPass`、`GizmoPass`、`ParticlePass`、`SpritePass`、`SceneRenderer`）が Scene 層の System を呼び、Scene 層の System（`CameraSystem`、`LightSystem`、`GizmoSystem`、`RenderSystem`、`SpriteSystem`）が Render 層の型を使っています。<br>どちらを上とみなすかは実装から決められません。選択肢は (a) System を Render 層へ移す、(b) パスが受け取る「描くもの」を Scene 側が用意して渡す、(c) 現状を許容してヘッダ単位の循環だけ禁止する、の 3 つです。 |
| `BuildConfig.h` と `ProjectSettings.h` の置き場所 | 2 つは Application 層のフォルダにありますが、Graphics 層（`SwapChain.h`）と Editor 層のほぼ全ヘッダから参照されています。層の規則に従うなら下位層が最上位層を参照していることになり、実質は「全層で共有する設定とビルド定義」です。<br>共有設定として Foundation か専用フォルダへ移すか、現状を許容するかを決める必要があります。                                                                                                                                                                                                             |
| Scene 層が ImGui に依存している    | `Scene/System/GizmoSystem.h` が `GizmoSettings` のために `imgui.h` と `ImGuizmo.h` を無条件に include しています。Scene 層は Release 構成にも含まれる層で、エディタ専用ライブラリへ依存しない設計のはずです。<br>`ImGuizmo::MODE` と `ImGuizmo::OPERATION` をエンジン側の列挙に置き換えれば Scene 層が ImGui から離れます。                                                                                                                                                                                                                      |
| アセット分類の列挙が 2 つある      | `Asset/Database/AssetDatabase.h` の `AssetType` と `Asset/AssetTypes.h` の `ImporterType` は、どちらも「ファイル 1 つの分類」を表します。`AssetDatabase::RegisterAsset` が `ToImporterType` で変換して `.meta` に書いており、`AssetTypes.h` 側のコメントは「フェーズ 5 で `AssetDatabase` と一緒に削除する」と書いています。<br>インポートパイプライン接続時に `ImporterType` へ統合する計画と読めますが、計画書はリポジトリにありません。                                                                                                                 |

## バグ
ビルドが通らない、想定と違う挙動をする、コメントと処理が食い違っているなど、コードの間違いを指摘する項目です。<br>
１行程度でまとめられる場合は解決方法を記述し、２行以上になる場合は省略します。<br>
<br>
危険度は以下のように分類されます<br>
| 危険度 | 基準                                                                                                                                           |
| :----: | :--------------------------------------------------------------------------------------------------------------------------------------------- |
|  超高  | 重大な欠陥。<br>逆にコンパイルエラーが起きない、メモリリークが発生するなど。<br>今すぐに対処が必要な欠陥。                                     |
|   高   | 重要なバグ。<br>計算方法が間違っている、初期値が間違っているなど。<br>複数機能にわたって問題を起こす可能性があるバグ。                         |
|   中   | 対処が必要な問題。<br>初期化が呼ばれていない、初期値とInitializeで値が違うなど。<br>厳しくassertを付けるとコンパイルエラーが起きる程度の問題。 |
|   低   | 軽微なミス。<br>コメントや変数名の誤字、includeが明示的でないなど。<br>最悪対処しなくても良いミス。                                            |

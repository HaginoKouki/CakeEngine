# 全体設計

CakeEngine は、役割ごとに機能を分けた階層構造で設計しています。各層は原則として自分より下の層だけに依存します。これにより、機能の責務と依存関係を明確にします。

## 層の一覧

| 層 | 責務 | 詳細 |
| --- | --- | --- |
| [Foundation](FoundationLayer.md) | OS に依存しない基礎機能を提供する | 数学、識別子、ログ、シリアライズなど |
| [Platform](PlatformLayer.md) | OS や実行環境の機能をエンジン向けに扱う | ウィンドウ、入力など |
| [Asset](AssetLayer.md) | ゲームで使う資産を識別・管理する | モデル、テクスチャ、マテリアルなど |
| [Graphics](GraphicsLayer.md) | DirectX 12 の機能を扱う | デバイス、リソース、コマンドなど |
| [Render](RenderLayer.md) | 描画対象を画面に出力する | 描画パス、カメラ、描画キューなど |
| [Scene](SceneLayer.md) | ゲーム世界とその状態を表現する | オブジェクト、コンポーネントなど |
| [Editor](EditorLayer.md) | ゲーム制作時の編集機能を提供する | インスペクター、シーン編集など |
| [Application](ApplicationLayer.md) | 起動から終了までアプリケーションを構成する | メインループ、各層の初期化など |

## 依存関係

基本ルールは「上位の層から下位の層を使う」です。下位の層が上位の層を直接参照すると、層の境界が崩れて変更の影響範囲が広がるため避けます。

各層の詳細ページには、担当する機能、配置場所、依存関係、および実装上のルールを記載します。コードと説明が異なる場合は、実装に合わせてドキュメントを更新してください。
